Projects I've built.

  • A SaaS platform where construction and electrical contractors manage customers, projects, sites, quotations, labour, materials and payments in one place, with every company’s data kept fully separate.

    • Building a multi-tenant SaaS ERP/CRM for construction and electrical contractors on a shared PostgreSQL database, with tenant isolation enforced at the Django/DRF layer.
    • Designed a module and role-based access control (RBAC) system: a Super Admin enables modules per tenant, and every request is checked for tenant, module status and role permission (view / create / edit / delete / approve).
    • Modelled core business entities including customers, projects, sites, BOQ and quotations, labour attendance, materials, expenses, payments and daily site progress.
    • Developing a React dashboard on top of the REST APIs, containerized with Docker for consistent development and deployment.

  • An AI-powered WhatsApp chatbot that books bus, flight and hotel tickets end to end, from conversation to payment to PDF ticket.

    • Built an AI-powered WhatsApp chatbot for bus, flight and hotel bookings using FastAPI, Twilio and Rasa NLU.
    • Integrated Razorpay payments, a form-link booking flow and automated PDF ticket generation sent directly on WhatsApp.
    • Built FastAPI webhook endpoints with session management to handle multi-step conversations and store bookings, users and payment status in MySQL.

  • A camera-based employee attendance system that recognises faces and records attendance automatically.

    • Camera-based employee attendance system using OpenCV and face recognition, with attendance records stored in MySQL.
    • Developed API endpoints for face-recognition-based attendance and Automatic Number Plate Recognition (ANPR) for smart parking.

  • A college management system built with Django to manage students, courses and testimonials.

    • Built with Django to manage student records and course information in one place.
    • Includes a testimonials module for showcasing student feedback.
