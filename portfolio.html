  • 01 Multi-tenant SaaS AI Construction ERP & CRM Multi-tenant ERP/CRM for construction and electrical contractors. Django · DRF · PostgreSQL · React · Docker

    A SaaS platform where construction and electrical contractors manage customers, projects, sites, quotations, labour, materials and payments in one place, with every company’s data kept fully separate.

    • Building a multi-tenant SaaS ERP/CRM for construction and electrical contractors on a shared PostgreSQL database, with tenant isolation enforced at the Django/DRF layer.
    • Designed a module and role-based access control (RBAC) system: a Super Admin enables modules per tenant, and every request is checked for tenant, module status and role permission (view / create / edit / delete / approve).
    • Modelled core business entities including customers, projects, sites, BOQ and quotations, labour attendance, materials, expenses, payments and daily site progress.
    • Developing a React dashboard on top of the REST APIs, containerized with Docker for consistent development and deployment.

    • Built an AI-powered WhatsApp chatbot for bus, flight and hotel bookings using FastAPI, Twilio and Rasa NLU.
